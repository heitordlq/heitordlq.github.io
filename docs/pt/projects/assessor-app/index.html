Assessor App

App em React Native e TypeScript que consome uma API configurável.

O que faz

  • Navegação entre telas com React Navigation.
  • Interface com componentes do React Native Paper.
  • Requisições HTTP com Axios e armazenamento local com AsyncStorage.
  • Testes automatizados com Jest.

Stack

React Native / TypeScript / React Navigation / React Native Paper / Axios / AsyncStorage / Jest
